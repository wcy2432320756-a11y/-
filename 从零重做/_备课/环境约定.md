# 备课环境约定（R 自用备忘）

## 编码：全目录 GBK
- 「从零重做」里所有 `.cpp` / `.h` 一律 **GBK 无 BOM**。
  依据：Dev-C++ 5.9.2 不认 UTF-8、连 BOM 也不认（2026-10 实测，BOM 被显示成"锘"）。
- 我（R）用工具写源文件时默认是 UTF-8 → **写完必须转码**：
  `python 从零重做\_备课\to_gbk.py`（自动备份到 `_备课\_utf8_backup\`）
- **读/改已转 GBK 的源文件**：read/edit 工具会报 "invalid UTF-8 text" ——
  用 python（`d.decode('gbk')`）打印内容，或直接用 write 按 UTF-8 重写整份再转码。
- `README.md` 保持 UTF-8；VS Code 已开 `files.autoGuessEncoding`，两种编码都正常显示。
- 绝对不要给 `.cpp` 加 BOM。
