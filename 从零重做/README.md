# 从零重做 · 图书馆借阅系统

不碰旧代码。从零把作业重新写一遍，每课只学一个小组件。

## 终点长什么样（作业要求）

- 图书信息：条码号、ISBN、书名、作者、出版社、是否可借 —— 可输入、输出、修改、查询
- 用户分两种：学生（学号）和教师（工号），各自有最大借阅数量
- 借书 / 还书，系统按日期判断逾期并计算罚款
- 资源分三类：一般图书、杂志、电子资源（继承 + 多态）
- 数据能存进文件，下次打开还在
- 全程有菜单，操作有提示

## 怎么用

**主路线：Visual Studio**
- 打开 `LibraryRebuild.sln` → 按 **Ctrl+F5**（开始执行不调试）→ 运行"当前课"
- 项目里能看到所有课的文件；**只有"当前课"参与编译**（每课都有自己的 main，
  多个 main 会打架）——换课由 R 维护项目，你不用管
- 想重跑旧课复习：用 Dev-C++ 打开那一课按 F11

**练习路线：Dev-C++ / VS Code / 命令行**
- Dev-C++：打开任意一课 → **F11**（编译并运行）
- VS Code：打开本文件夹 → 某一课 → **Ctrl+Shift+B**
- 命令行：`.\run.ps1 step01`（只编译：`.\run.ps1 step01 -NoRun`）

**编码约定：本目录源码统一 GBK**（中文 Windows 的老习惯，Dev-C++ 的原生编码）。
不管用哪个工具打开，中文都应正常显示（VS Code 已开启自动识别）。
